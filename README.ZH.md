# pi-cd-workspace

[English](README.md) | **[简体中文](README.ZH.md)**

独立的 Pi 工作目录扩展：保留会话切换、新建空会话，或打开 Pi 原生恢复列表。从 pi-file-sidebar 完整拆出目录选择器、鼠标导航、位置条、完整名称气泡及中英文界面。

要求 Node **>=22.19.0**、Pi **>=1.4.0 正式版**（允许构建元数据，拒绝预发布）。**宿主补丁是可选增强，默认不安装。** 原版 Pi 上的 `/cd`、`/cd-new`、`/cd-resume` 直接沿用原切换逻辑，不会因缺少补丁接口而拒绝执行；若你手动使用带 [Pi 1.5.2 补丁](patches/README.md)的宿主，扩展会检测接口并启用额外保护。支持 fullscreen 和 regular TUI；RPC/print/JSON 静默。扩展本身无需构建、无运行时依赖，由 Pi 加载 `extensions/index.ts` 并提供 SDK/TUI。

## 安装与迁移

直接使用现有 Pi 即可。安装或 `/reload` 本扩展不会安装宿主补丁，也不会改写 Pi 本身。[可选补丁说明](patches/README.md)只供需要额外保护的用户参考，原流程不需要额外配置。

从 GitHub 安装扩展：

```bash
pi install git:github.com/llc2214926/pi-cd-workspace
# 然后 /reload 或重启 Pi。
```

本地开发时，可在源码仓库中临时加载，不注册包、不加载其他已安装扩展：

```bash
pi --no-extensions -e ./extensions/index.ts --tui-mode fullscreen
# 可选：共同加载拆分后的侧栏，顺序可交换。
pi --no-extensions -e ./extensions/index.ts -e ../pi-file-sidebar/extensions/index.ts --tui-mode fullscreen
```

**启用本扩展前，先把 pi-file-sidebar 安装副本更新为拆分后的源码。** 旧侧栏安装和旧 `~/.pi/agent/extensions/cd-picker.ts` 也注册 `/cd`，不能与本包同时启用。请先备份旧安装。修改源码不等于更新安装副本；本扩展不会自动安装、停用或改写其他扩展。

旧 `/file-sidebar cd` 别名和侧栏目录菜单中的切换动作已删除，不做转发。改用 `/cd` 浏览或 `/cd <编码路径>` 直接切换。现有会话、`cd-picker` 标记、`.cd-backup` 和 `.cd-abandoned` 文件继续兼容，无需迁移会话。语言改由本扩展独立管理，需要英文时执行 `/cd-workspace lang en`；不会读取或修改侧栏语言偏好。

若需要独立分发副本，执行 `npm pack`，把其中 `package/` 解包到新目录，再 `pi install` 该目录。不要同时注册源码和打包副本。包内含运行源码、两份 README 和带说明的宿主补丁，不含测试、开发依赖或构建产物。

## 命令

| 命令 | 不同实际目录 | 当前实际目录（含别名/符号链接） |
|---|---|---|
| `/cd [编码路径]` | 保留当前会话/历史，恢复草稿文本 | 仅提示，不切换 |
| `/cd-new [编码路径]` | 新 ID、空对话和草稿 | 原生 `/new` |
| `/cd-resume [编码路径]` | 新建空会话后打开原生 `/resume` | 只打开 `/resume`，不新建会话 |
| `/cd-workspace` | 显示用法 | 相同 |
| `/cd-workspace lang [zh\|en]` | 切换并保存语言；省略语言时查看 | 相同 |

三个 cd 命令不带路径时均打开同一选择器。参数是 **URI 编码路径**，不是 shell 引号字符串，例如 `/cd %2FUsers%2Fme%2FMy%20Project`。对完整路径执行一次 `encodeURIComponent`。相对路径以 `ctx.cwd` 为基准，支持 `~` 和 `~/…`；拒绝无效编码和 NUL。确认目标后重新执行 `realpath`、目录类型及读/执行权限检查；明确指定的符号链接路径会解析到实际目录。不执行 shell。

请在主输入框中、Pi 空闲且无运行中的 shell、待发送消息或阻塞 UI 时执行。三个命令共用在途锁，不能互相重叠。其他组件持有焦点时（包括侧栏导航、调宽和外部编辑器），先返回主输入框；本扩展不会强行关闭它们。选择后再次检查空闲和 UI 状态。`/cd` 及跨目录切换要求持久化；同目录新建/恢复支持 `--no-session`。

## 目录选择器

居中双线边框浮层占终端宽度 85%，含边框不超过高度 90% 且最多 30 行，不接管持久布局。分栏之间有竖线，长名称用省略号。主题和语言变化只重绘，不重读目录。

每栏目录在前、普通文件在后，两组按名称排序。文件始终淡色、不带 `/`；可以选中查看全名，但不能进入、确认、打开或读取。符号链接和特殊项不列出。仅异步读取已进入层级，不递归、不 watcher、不轮询；区分加载中、无可见项和读取失败，离开分栏或销毁后的迟到读取不会提交。

| 输入 | 行为 |
|---|---|
| ↑ / ↓、j / k | 移动选择；长按方向键约 1.1s 后每次 2 项，2.6s 后 3 项 |
| ← | 返回父目录/上一栏 |
| → / l | 进入高亮目录；文件无动作 |
| .（也支持 。） | 显示/隐藏点项和 `node_modules` |
| r | 返回打开选择器时的工作区，选中其 `.` 行；不是刷新或确认 |
| Enter | 确认高亮目录，包括 `.` 行；文件无动作 |
| Esc / Ctrl+C | 取消，不生成会话快照或备份 |
| 鼠标左键（fullscreen） | 文件和 `.` 仅选中，目录选中并进入；**不确认切换** |
| 滚轮（fullscreen） | 仅滚动鼠标所在栏，不改变选择、活动栏或焦点 |
| [ / ] | 完整名称气泡内容溢出时翻页 |

换向、停顿超过 450ms 或非方向键操作后加速复位；j/k 始终单步。只依赖终端自动重复，不新增计时器或读取。`r` 收回后续分栏、清空偏移、收起气泡，保留隐藏项开关，尽量复用工作区栏。`h` 在选择器中无动作；`l` 导航而非语言切换。

每栏滚离顶部后有独立的右侧位置条，非活动父栏也保留，空闲时不消失；回顶或所有项目能放下时隐藏。预留一列正文宽度（仅剩一列时优先正文），不支持拖动/点击。在位置条上滚轮仍滚动所属栏。边界、边框、标题、页脚、分隔线和加载/错误行消费滚轮，不传给主对话。滚动不读取目录；键盘移动后重新露出选中项。

点击可见父栏会收起其旧后代栏。标题、页脚、分隔线、位置条、空白/加载/错误行、右键、悬停和拖动不导航。读取或布局变化后旧鼠标坐标不会误选新行。regular TUI 仍只用键盘。

选中被截断的名称自动显示不捕获焦点的圆角全名气泡，最多 80 列 × 12 行，限制在终端内。可以越过分栏，按显示宽度换行，支持 `[` / `]` 和气泡内滚轮翻页；不改变选择和焦点。选中项滚出视口、名称可完整显示或选择器关闭时收起。名称、路径和错误只清洗显示，实际磁盘路径不变；不读取正文进入模型上下文。

## 会话与失败安全

- `/cd` 以 `0600` 权限独占创建 JSONL 快照，保留当时已有的 ID、头部元数据、条目/分支及当前 leaf；不进入模型上下文的 `cd-picker` 标记记录 `{ from, to }`。**不会自动恢复目标项目的上次会话。**
- **默认不安装补丁：**沿用原来的 `isIdle()` / 待发送消息检查和 `switchSession()`，快照仍在关闭会话前生成。
- **手动使用补丁宿主：**改用 `switchSessionWhenIdle()` 预留空闲状态，包括用户 shell 和异步 shell 钩子；所有 `session_before_switch` 和 `session_shutdown` 保存完成后原子更新快照，**然后宿主才加载目标**。增强切换失败时不会再次调用原接口重试。
- 两种流程均按 Pi trust 规则重建 cwd 相关资源、工具和扩展。不执行 `process.chdir`、运行时猴子补丁、命令消息桥接或模型调用。切换后的操作只使用新的 `withSession` 上下文。
- `/cd` 恢复草稿文本，但**不保证光标位置**，失败会告警。取消选择器保留原编辑器对象和草稿。
- 确认接管后，`/cd` 将源文件归档为 `.cd-backup`，重名加 UUID；尚未落盘的源无需归档。`EXDEV` 回退独占复制并保留原件、告警。归档失败时目标会话继续使用，源文件保留。
- 新建模式不复制旧消息、分支、摘要、名称、扩展状态、父会话关联或草稿，本扩展也不归档/修改原会话；旧宿主的关闭钩子仍可正常保存到原会话。跨目录时生成仅含新头部的 JSONL，再调用 `switchSession()`（有增强接口时用 `switchSessionWhenIdle()`）；生命周期原因是 `resume`，但 ID/历史是新的。同目录 `/cd-new` 调用 `newSession()`，仅增强宿主附加 `requireIdle: true`，不生成中转文件。
- 默认会话存储跟随目标目录；显式配置的存储目录保持不变。
- 宿主取消或接管前可捕获错误，将中转文件隔离为 `.cd-abandoned`（重名加 UUID），不删除。部分写入也尽量隔离；失败则报告存留路径。备份/隔离文件不会出现在 `/resume`。
- 原生恢复调用当前编辑器的 `app.session.resume` 动作。列表、搜索、范围、改名/删除和取消均由 Pi 管理，不自动选历史。跨目录后取消恢复列表停留在目标空会话，同目录取消保留原会话。自定义编辑器能力缺失则告警，不向模型发送 `/resume`；接管后列表打开失败仍保留目标会话，可手动执行 `/resume`。

**原流程的已知限制：**没有补丁时，Pi 的空闲判断可能漏掉运行中的 shell，切换可能中断它；关闭时新保存的状态可能只留在源备份中，未进入活动副本。这些限制不会阻止命令执行。建议先等 shell 完成再切换；需要额外保证时可自选补丁。

**宿主致命错误限制：**Pi 可能先销毁旧 runtime，再因替换失败直接退出，扩展来不及 catch。致命退出/进程终止时不保证自动 UI 回滚或隔离。切换前显示两个文件路径，确认接管前不归档原件。可用 `pi --session '/原会话绝对路径.jsonl'` 重启恢复；确认未被使用后再手动处理遗留的目标 `.jsonl`。不要破坏活动会话模拟错误。

## 独立性与语言

本扩展只拥有 `/cd`、`/cd-new`、`/cd-resume`、`/cd-workspace` 和自有临时浮层。不注册全局快捷键，不修改主编辑器/页头/页脚/布局，不导入侧栏代码。临时宿主探针使用独立命名空间并同步移除。shutdown 只关闭自己的选择器/气泡，等待自己的语言保存，不等待触发 shutdown 的切换命令。

拆分后的侧栏拥有 `/file-sidebar`、Ctrl+Shift+E、自己的布局和 `file-sidebar.json`。任一方可以缺席；只通过宿主原生 prompt/焦点/会话生命周期共存，没有私有事件桥接。侧栏 off/on 和语言变化不取消/重配 cd 选择器。会话替换后侧栏自然重建根并恢复默认宽度，这是宿主行为，不是互相控制。

首次默认中文。`/cd-workspace lang en` 或 `zh` 只保存 **`getAgentDir()/cd-workspace.json`**，遵循 `PI_CODING_AGENT_DIR`；不碰 Pi settings、keybindings、项目配置、安装副本或 `file-sidebar.json`。

```json
{ "language": "en" }
```

启动只读，缺失时默认中文。明确切换后串行保存，使用同目录私有临时文件原子替换，保留未知字段；正常 shutdown/reload 等待保存。拒绝符号链接、非普通文件、无效 JSON/UTF-8/语言和超过 16 KiB 的文件；不覆盖损坏配置。保存失败告警，本次选择仍有效。无 watcher，其他 Pi 进程下次启动/reload 读取最后成功保存的值。只翻译本扩展文案，不翻译路径、正文或 Pi 自带界面。

## 开发与验收

```bash
npm install --ignore-scripts
npm run typecheck
# 本地回归，不进入 Git 或发布包
./node_modules/.bin/tsc -p tests/tsconfig.json
node --import tsx --test tests/*.test.ts
npm pack --dry-run
```

本地检查覆盖会话/文件系统失败、控制字符转义与正常多行提示、选择器渲染/输入，以及 fullscreen/regular 下的单独/共同加载。真实未补丁 runtime 验证三个目录命令、同目录/跨目录和原生恢复列表；单元检查覆盖原接口与增强接口两条流程。另外在打补丁的 1.5.2 真实离线 runtime 中加载本扩展，使用独立会话和内存终端，验证真实子 shell、关闭时保存、新建会话及最终写入失败。见[宿主验证与限制](patches/README.md)。

这些检查不替代正式人工真实终端验收，后者仍待完成。最近一次后台 PTY 尝试在 Pi 启动前被环境拒绝（`os.openpty`: `Operation not permitted`）；拆分后的实际终端会话替换/reload 尚未重新验收。
